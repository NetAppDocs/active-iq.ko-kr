= Digital Advisor에서 스토리지 시스템에 대한 시스템 업데이트가 권장되는지 확인합니다
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Tech Support 계약 또는 하드웨어에 대해 시스템 새로 고침이 권장되는지 확인하려면 시스템 새로 고침 옵션을 사용할 수 있습니다.

이 기능은 수명 주기 계획(*스토리지* > *수명 주기 계획*) 또는 Digital Advisor(*대시보드* > *계획 위젯* > *시스템 새로 고침*)를 통해 액세스할 수 있습니다.

이 기능에 대한 자세한 내용은 콘솔 설명서의 link:https://docs.netapp.com/us-en/console-lifecycle-planning/use/tech-refresh.html["시스템 새로 고침 평가"]을(를) 참조하십시오.
