= Digital Advisor 에서 작업에 대한 위험을 확인하고 Unified Manager 또는 Ansible Playbook을 사용하여 위험을 완화하십시오.

[role="lead"]
조치 및 위험을 확인하여 스토리지 시스템을 분석하고 Active IQ Unified Manager 또는 Ansible 플레이북을 사용하여 완화할 수 있습니다.

video::XusFvXM7h-E[youtube,width=848,height=480]
.단계
. 대시보드에서 *View All Actions* 를 선택합니다.
. *작업*을 선택하면 해당 작업과 관련된 위험을 볼 수 있고, *위험*을 선택하면 모든 위험을 볼 수 있으며, *영향을 받는 시스템*을 선택하면 주의가 필요한 시스템을 볼 수 있습니다.
+
Active IQ Unified Manager를 사용하여 위험을 완화할 수 있는 경우, 를 참조하십시오 image:spanner.png["스패너"] 아이콘이 강조 표시되고 Ansible Playbook을 사용하여 위험을 완화할 수 있는 경우 가 표시됩니다 image:update_ansible.png["Ansible 업데이트"] 아이콘이 강조 표시됩니다.



[cols="50,50"]
|===
| Unified Manager를 사용하여 위험을 완화하십시오 | Ansible 플레이북을 사용하여 위험을 완화하십시오 


 a| 
. image:spanner.png["스패너"] 아이콘을 선택합니다.
. *Fix It* 을 선택하여 Active IQ Unified Manager를 실행합니다.
. *설치*를 선택하여 Active IQ Unified Manager 9.7 이상 버전을 설치하고 *Fix It* 옵션을 사용하십시오.
. *업그레이드*를 선택하여 Active IQ Unified Manager 9.7 이상으로 업그레이드하면 *Fix It* 옵션을 사용할 수 있습니다.

 a| 
. image:update_ansible.png["Ansible 업데이트"] 아이콘을 선택합니다.
. AFF 및 FAS 펌웨어 Ansible 자동화 패키지를 다운로드하려면 *다운로드*를 선택하십시오.


|===

NOTE: SupportEdge Expert 또는 SupportEdge Advisor 계약은 * Fix it * 옵션 및 Ansible Playbook 기능을 사용하기 위해 필요합니다.
